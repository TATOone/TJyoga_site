# Страница тарифов TJ Yoga

Отдельная лёгкая страница с описанием двух тарифов Онлайн Йога-Клуба. Не связана с основным сайтом.

**Назначение:** быстрый просмотр тарифов по ссылке (в т.ч. внутри Telegram, без перехода во внешний браузер).

## Содержимое

- **Месячная подписка** — 6 000 ₽/месяц  
- **Годовая подписка** — 60 000 ₽/год (со скидкой)

Стиль совпадает с палитрой основного сайта (терракотовый, оливковый, тёмно-коричневый, светлый фон).

## Как использовать

1. **Локально:** открой `index.html` в браузере или подними любой простой сервер из корня папки `rates`, например:
   ```bash
   cd rates && npx serve .
   ```
2. **В Telegram:** залей папку `rates` (или только `index.html`) на хостинг и давай клиентам ссылку на `https://ваш-домен/rates/` или прямо на `https://ваш-домен/rates/index.html`.

## Размещение

- **Подпапка основного домена:** при деплое сайта (GitHub Actions) папка `rates` копируется в `dist/rates/`, поэтому тарифы доступны по адресу `https://ваш-домен/rates/` (или `https://username.github.io/репозиторий/rates/` на GitHub Pages).
- Можно также выложить на отдельный поддомен (например `rates.tjyoga.ru`).
- Страница самодостаточна: один HTML, стили внутри, без скриптов и сборки — подходит для любого статического хостинга.

## Редактирование

- Тексты, цены и ссылки на оплату правь прямо в `index.html`.
- Ссылка на оплату для годового тарифа сейчас совпадает с месячным (`payform.ru/t5a23mO/`). Если у тебя отдельная форма для года — замени `href` у второй кнопки.
