# Изображения для отзывов

Поместите сюда 3 изображения для аватарок отзывов:

1. **natalya.jpg** - Аватарка для Натальи (женщина в шляпе с вороной)
2. **yuliya.jpg** - Аватарка для Юлии (блондинка с синими очками на фоне гор)
3. **ekaterina.jpg** - Аватарка для Екатерины (женщина в бандане на холме с морем)

**Требования:**
- Формат: JPG, JPEG или PNG
- Размер: минимум 200x200px, рекомендуется 400x400px или больше
- Квадратные изображения будут отображаться лучше всего (для круглых аватарок)

После сохранения файлов с указанными именами, они автоматически отобразятся на сайте.
